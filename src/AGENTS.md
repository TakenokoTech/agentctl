# src/AGENTS.md

書き方は、ルートの `AGENTS.md` の注意書きに従う。層構成と依存のルールは `.agent/architecture/SKILL.md` に従う。

## ファイルの分け方

- 分割の基準は凝集度。ファイルの役割を、「と」を使わずに一文で説明できる単位にする。
- 行数そのものを分割の理由にしない。テストを除いた本番コードが 200 行前後を超えたら、責務が混ざっていないかを見直す。
- 関数の長さと複雑度は、行数ではなく clippy の `too_many_lines` と `cognitive_complexity` で縛る。

## テストの置き場所

- 単体テストは、例外なく `#[cfg(test)] mod tests;` として `<モジュール名>/tests.rs` に置く。ファイルごとに置き方を変えない。
- 実バイナリを起動して検証するテストは `tests/` に置く。
